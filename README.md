## 📊 Methodology & Activity

Activity badges are updated automatically via daily GitHub metadata tracking:

- `🟢 Active`: Pushed to within the last 90 days.
- `🟡 Maintained`: Pushed to within 91–365 days.
- `🟠 Quiet`: Pushed to within 366–730 days (1–2 years).
- `🔴 Inactive`: No push for over 2 years.
- `⚫ Archived`: Repository is officially archived on GitHub.
